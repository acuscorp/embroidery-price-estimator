# Plan de trabajo

Tomaremos como guía las clases del curso **Software Architecture** y adaptaremos sus conceptos y actividades al proyecto **Cotizador de Bordados**.

La ruta curricular y los documentos oficiales de las clases indican qué estudiar y en qué orden. Aplicaremos ese contenido al cotizador y la información obtenida se incorporará a los doce archivos de documentación **arc42**, creando, añadiendo o actualizando lo que corresponda.

## Alcance y restricción

El proyecto se limita exclusivamente al **análisis y diseño de arquitectura de software**.

- El código existente podrá consultarse como evidencia para comprender y analizar el sistema.
- No se implementarán funcionalidades, ni se programará, refactorizará o modificará código.
- No se crearán, modificarán ni eliminarán archivos de código.
- Esta restricción permanecerá vigente durante todo el trabajo. **Cualquier cambio en el código requiere autorización explícita del usuario.**
- La autorización para modificar documentación arquitectónica no implica autorización para modificar código.
